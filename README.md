# GSA Leads Dashboard
Static GitHub Pages dashboard for the Supabase `public.gsa_leads` table.

## Setup
1. Edit `config.js` and add your Supabase Project URL and publishable key.
2. Configure Supabase RLS before publishing.
3. Upload these files to a GitHub repository.
4. GitHub repo > Settings > Pages > Deploy from a branch > `main` > `/(root)` > Save.

Never use a Supabase secret/service_role key in this project.
